Boulevard School: an accessible site built right the first time

A from-scratch Webflow build, taken from a finished Figma design to a live, ADA-compliant school website.

IndustryEducation
Built fromFigma design
ServicesWebflow Development, ADA Compliance

The challenge

Boulevard School came in with a finished Figma design and a hard requirement most agencies treat as an afterthought: the site had to meet ADA accessibility standards from day one, not get patched for compliance after launch. That meant screen-reader-friendly markup, proper heading structure, color contrast, and keyboard navigation all had to be designed into the build itself, not bolted on with an accessibility widget.

The approach

The Figma file was reviewed component by component before any build work started, checking not just the visual design but what each element would need semantically to work with assistive technology. From there the site was built in Webflow with a clean, reusable class structure and accessibility considered at every layer.

  • Semantic heading structure and proper alt text on every image, not just the ones that were easy to catch
  • Color contrast checked against the Figma palette before build, so nothing had to be reworked after the fact
  • Full keyboard navigation tested across the site, not just the homepage

The result

A live site that matches the Figma design precisely and meets ADA accessibility standards without a bolted-on widget pretending to do the job. The school got a site they can point to as genuinely accessible, and one their own team can still edit without touching code.
